# CRun a C runner for quick tests

usage exemple : 
```crun main.c``` 

intended execution :

```crun execution -> gcc compilation -> code execution -> compiled files deletion```

### Why this project ? 

Im too lazy to run 3 commands when i test my code, so i made this.
(thats not really what the lazyness is)
